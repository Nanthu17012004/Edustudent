# EduFlow Student Management System

A responsive React-based student management dashboard with separate Admin and Parent portals.

## Features

- Landing page
- Admin dashboard
- Parent dashboard
- Student CRUD-style demo flow
- Course management UI
- Academic calendar
- Payments
- Inbox
- Profile/settings
- Responsive sidebar and mobile navigation
- Recharts dashboard graphs
- Local demo data
- Simple EduFlow AI assistant

## Run

```bash
npm install
npm start
```

Open http://localhost:3000

## Demo

Go to `/login`.

Choose **Admin** or **Parent**. Any valid email/password works because this project uses demo frontend authentication.

## Important

This is a frontend demo. Real authentication, database storage, API security and production authorization should be connected before deployment.
